# lct plugin validate

Validate that a local plugin can run repeatedly

## Usage

```bash
lct plugin validate PLUGIN
```

## Examples

```bash
lct plugin validate .
```

```bash
lct plugin validate ./plugins/example
```

## Arguments

#### *PLUGIN*

Path to a local plugin directory

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes
