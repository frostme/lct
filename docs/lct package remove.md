# lct package remove

Remove a package from a manager-specific tracked list

## Usage

```bash
lct package remove MANAGER PACKAGE
```

## Arguments

#### *MANAGER*

Registered package manager name

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes

#### *PACKAGE*

Package name to stop tracking

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes
