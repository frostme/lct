# lct package add

Add a package to a manager-specific tracked list

## Usage

```bash
lct package add MANAGER PACKAGE
```

## Arguments

#### *MANAGER*

Registered package manager name

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes

#### *PACKAGE*

Package name to track

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes
